# SahaySetu — Bridge to Help

*AI-powered NGO volunteer coordination platform for India.*

## What it does
SahaySetu helps NGO coordinators , volunteers to report and manage community needs in real time. Field workers describe a situation in Hindi or English via text or voice, and Gemini AI automatically extracts the location, urgency, resource type and priority score then plots it on a live map.

## Tech Stack
- Google Gemini AI (via Puter.js)
- Leaflet.js — interactive map
- HTML/CSS/JavaScript
